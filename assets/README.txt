Drop your LEU logo here as:  logo.png

The bot uses it automatically:
  • /setup           → sets it as the SERVER ICON (needs Manage Server permission)
  • npm run avatar   → sets it as the BOT'S AVATAR (run once; Discord rate-limits avatar changes)

PNG or JPG both work; square images look best. Recommended at least 512x512.
(If no logo.png is present, the bot simply skips this — nothing breaks.)
